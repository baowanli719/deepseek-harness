# 桌面更新准备与重启

[English](guide.md) | 中文

## 变更

桌面更新展示在文件校验和就绪之间增加 `preparing` 阶段。GS macOS 更新会暂存已签名的应用，在用户确认安装后使用原生更新器替换程序并自动重启。下载、校验和准备期间保留进度弹窗。在知道文件长度前不提供下载百分比；本地准备不显示虚构的百分比。

## 迁移

1. 自定义桌面更新展示方需将 `preparing` 视为忙碌状态，并允许下载期间缺少 `percent`。
2. 通过客户端的下载和重启确认安装 GS 更新。macOS 无需从打开的 DMG 手动复制应用。已安装应用和更新必须具有相同 Team ID 并通过 Gatekeeper；未签名开发版本无法使用此原生更新路径。
3. 准备失败时从仍在运行的客户端重试。普通退出不会安装更新。现有对话数据保留在对应产品的主目录中。
