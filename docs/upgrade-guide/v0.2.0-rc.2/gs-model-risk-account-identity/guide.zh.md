# GS 模型风险签署人信息

[English](guide.md) | 中文

## 变更

模型风险签署请求不再要求或转发 `fullName` 和 `email`。GS 服务端从当前认证账号和员工目录读取姓名与邮箱。模型列表行锁图标在切换前打开协议；取消时保留原模型。

## 迁移

1. 先部署 GS 服务端更新，再更新客户端。确认账号具备姓名和在职员工目录邮箱。
2. 签署调用方仅发送 Provider、模型 ID、revision、确认状态及手写轨迹，移除客户端身份字段。
3. 更新 GS 客户端，确认选择未签署模型先打开协议再切换。签署存档编号返回后放行并提供 PDF 下载；存档身份和邮件收件人必须对应服务端账号。
